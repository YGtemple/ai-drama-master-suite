## 核心铁律

- 默认使用 Seedance 2.5 引擎，提示词原文透传
- 生成前展示完整提示词，强制图片参考并@艾特人物
- 强制多图参考，禁止把前一镜末帧当首帧
- 视频以内嵌预览播放器交付，生成阶段自动连续生成下一镜
- 有台词写进提示词，不用TTS
- 成片默认硬拼接不主动剪辑，全片零字幕（黑底时间跳转卡除外）
- 拼接仅用硬切，不用转场特效
- 不含去水印内容
