## 项目简介

**AI 短剧全能大师**是一套面向 AI 短剧/动态漫/剧情视频创作的全流程工作流规范。无论你处于创作的哪个阶段——只有一个想法、已有剧本、需要分镜、需要提示词、需要批量生成视频、需要审核质量、需要硬拼接交付——都能在本套件中找到对应的标准化工作流。

本套件基于多个真实 AI 短剧项目（如《斗罗·六子觉醒》56 镜全流程制作）的实战经验总结，所有规范均经过实际生成验证，可直接复用于后续项目。

> **整合说明**：本仓库已整合 `video-master-suite`，是唯一的统一视频 / 短剧技能入口（原 `video-master-suite` 仓库将在 GitHub 删除，请以本仓库为准）。

### 设计理念

- **镜头服务叙事，不为炫技** — 每一个技术决策都以叙事效果为最终评判标准
- **每一个交付物必须可直接使用** — 不输出半成品，不输出需要用户二次加工的模板
- **每幕自检后用户确认驱动** — 模块之间用户确认后再推进
- **物理可行性优先** — 所有景别/焦段/机位/运镜必须先匹配场景物理空间
- **每3-4秒一个信息点** — 节奏紧凑，杜绝空镜拖时间

## 核心特性

### 全链路覆盖

从 0 到 1 完整制作短剧，八大模块环环相扣，每个模块的产出是下一个模块的输入：

```
想法 → 剧本 → 分镜 → 提示词 → 视频片段 → 审核通过素材 → 硬拼接成片
```

### 双时长支持

| 时长 | 结构 | 适用 |
|------|------|------|
| **90 秒** | 四幕高密度结构（开场强冲击→核心冲突→反转爆发→结尾悬念） | 竖屏短剧、单集爆款 |
| **5 分钟** | 五阶段专业工作流（定位→世界观→首尾双锁→四幕推进→分段落地） | 系列短剧、精品短片 |

### 五大赛道

- 都市日常 / 言情 / 家庭
- 都市 / 玄幻脑洞
- 古风 / 仙侠 / 神话二创
- 悬疑 / 科幻 / 末日
- 开放赛道

### 九大结构原型

单空间高压对峙、倒计时规则收缩、交易代价升级、身份关系错位揭底、错误解法反噬、仪式中断夺权、系统失控推演、多维视角塌缩、绝对规则置换。

### 多引擎支持

| 引擎 | 定位 | 特点 |
|------|------|------|
| **Seedance 2.5** | ⭐ 最高优先级默认引擎 | 5-30 秒，6 种比例，提示词原文透传 |
| 即梦（横屏电影/竖屏/通用） | 备选 | 阿莱 65 电影质感、末世水世界风格 |
| MiniMax H3 | 备选 | 文戏/武戏/九宫格三流程 |

## 八大模块

### 模块 1：剧本创作

**输入**：想法 / 题材 / 一句话故事
**输出**：完整剧本（90 秒短剧 或 5 分钟短剧）

- 90 秒四幕时间锁 + 5 分钟五阶段工作流
- 五大赛道、九大结构原型、三大叙事重心
- 高级编剧技巧：三秒钩子、反转三层结构、台词功能检查、人物反差公式
- AI 短剧适配：少写复杂肢体接触、人物造型数量受控、抽象设定转化为道具/屏幕信息

📖 详细规范：[`references/01-script-creation.md`](references/01-script-creation.md)

---

### 模块 2：分镜设计

**输入**：剧本 / 小说片段
**输出**：标准化分镜脚本（中文画面规格书 或 结构化分镜组）

- **专业电影级镜头语言约束**：
  - 光源动机铁律（每一处亮度必须有明确来源、方向与真实衰减）
  - 纵深主层机制（禁止用 fog/haze/blur 当万能纵深捷径）
  - 五层色彩思维（palette / saturation / film_stock / grain / halation）
  - 物理可行性铁律（7 类场景空间适配矩阵）
  - 情绪-镜头匹配与反规则
  - 人物出现节制（非人物镜头占比 30%-50%）
  - 重技法频率上限（Dolly Zoom ≤1 次、环绕 ≤3 次等）
- **双输出格式**：中文【标签】块画面规格书（给人看）+ 结构化分镜组 V2.0 PLUS（给 AI 用）
- 长台词拆分规则

📖 详细规范：[`references/02-storyboard-design.md`](references/02-storyboard-design.md)

---

### 模块 3：提示词生成

**输入**：分镜脚本 + 用户提供的人物参考图
**输出**：可直接粘贴的 AI 视频生成提示词（含人物 @艾特 + 图片参考）

- **MiniMax H3 三流程**：文戏模式（关系变化/对白/微表情）、武戏模式（高密度打斗）、九宫格模式（先生成 3×3 关键画面）
- **即梦/Seedance 三引擎**：横屏电影质感（阿莱 65）、竖屏 Seedance 末世水世界、通用竖屏
- **强制图片参考 + @艾特人物**：用户提供的人物图片必须在提示词中用 `@图片N` 格式艾特，每次生成必须带参考图，不用纯文字
- **人物图片一人一角色**：用户给的人物图一人一角色，多余角色纯文字描述
- **全正向描述结构**：只陈述"生成什么"，不写"不要什么"
- **台词与环境音写入提示词**：有台词必须写进提示词，让 AI 直接生成带语音的视频，不用 TTS；需要的真实环境音（脚步/雨/风/水流/虫鸣/火焰/衣物摩擦/门轴/马蹄/人群/犬吠等）也写进提示词，由模型直接生成

📖 详细规范：[`references/03-prompt-generation.md`](references/03-prompt-generation.md)

---

### 模块 4：视频生成执行

**输入**：提示词列表 + 角色锚定图
**输出**：批量生成的视频片段（内嵌预览播放器 + 公共链接）

- **Seedance 2.5 最高优先级**：固定 `model_version=seedance_2.5`，提示词原文透传不改写
- **生成前必须展示完整提示词**：用代码块展示完整提示词（含人物 @艾特），展示后即生成，不等待确认
- **强制图生视频**：每次生成必须带参考图，不使用纯文字生成
- **生成任务卡**：每镜建立任务卡（Prompt / 参考图 / 模式 / 优先级 / 依赖 / 状态）
- **批次策略**：按场景分组，同场景同批生成，单批 ≤6 镜
- **优先级调度**：P0 反转/高潮/悬念镜优先，P1 核心冲突次之，P2 过渡镜最后
- **连续镜首帧处理**：前一镜末帧作为后一镜首帧参考
- **重试与版本管理**：每镜 2-3 版本，最多重试 3 次，3 次后导演决策
- **内嵌预览播放器交付，模块内自动连续生成**：每镜以内嵌预览播放器形式交付并附公共链接，模块4内部自动连续生成下一镜（不逐镜暂停等确认）；整批/整场生成完后统一自检展示，用户确认后才进入模块5

📖 详细规范：[`references/04-video-production.md`](references/04-video-production.md)

---

### 模块 5：质量审核 + 一致性管理

**输入**：已生成的视频片段
**输出**：审核报告 + 一致性检查报告 + 修复方案

- **七维逐镜审核**：画面质量 / 角色一致性 / 动作自然度 / 场景还原度 / 镜头语言 / 合规安全 / 时长节奏
- **AI 问题诊断库**：面部崩坏、换脸、多余手指、肢体扭曲、场景跑偏、光影异常等 20+ 常见问题，每个问题附原因和修复方案
- **分级修复策略**：轻度（调 Prompt 重生成）/ 中度（换镜头设计）/ 重度（重新规划）——问题一律在生成端解决，不依赖后期剪辑掩盖
- **四维跨镜一致性追踪**：角色一致性 / 场景连续性 / 光影衔接 / 道具追踪
- **道具出场追踪表**：关键道具逐镜记录持有者、位置、状态
- **面部 + 服装双锁检查**：跨镜核对面部不崩、服装同阶段锁死（见铁律 15/16/24）

📖 详细规范：[`references/05-quality-consistency.md`](references/05-quality-consistency.md)

---

### 模块 6：硬拼接交付（不剪辑）

**输入**：审核通过的多段视频素材（视频自带角色对话语音）
**输出**：按镜头顺序无损硬拼接的成片（原画质零压缩，全片无字幕）

- **默认只硬拼接，不主动剪辑**：所有镜头按顺序 concat 流拷贝拼接即成片——不裁剪、不调速、不混剪、不蒙太奇、不加片头片尾卡、不做节奏再编排；除非用户明确要求剪辑，否则不进入后期流程
- **无损流拷贝**：统一用 concat demuxer / `-c copy`，过程零重编码、零压缩，保持原始分辨率/帧率/码率/编码
- **拼前统一规格**：各镜头分辨率/帧率/比例不一致时，回源头统一导出，不靠对成片重编码"对齐"
- **拼后音画同步校验**：逐段核对音频与画面是否同步、拼接点有无卡顿/黑场/错位
- **声音政策：无人为配乐 BGM，保留真实环境音**：禁止混入任何歌曲/情绪配乐/钢琴弦乐 score 等人为配乐（BGM），以免干扰用户后期；真实环境音（脚步/雨/风/水流/虫鸣/火焰/衣物摩擦/门轴/马蹄/人群/犬吠等）由模型直接生成、可写进提示词，硬拼接时原样保留，并注意相邻镜头环境音的边界衔接
- **后期剪辑/调色用户自理**：本模块不做调色、不加速掩盖卡顿；这些后期处理由用户自行完成（需要时再单独沟通）
- **全片仅硬切硬拼接**：禁止淡入淡出/闪白/闪黑/叠化/匹配切等任何转场特效
- **全片零字幕**：台词靠视频自带语音传达，不打字幕（时空跳转黑底白字卡除外，见铁律 20）

📖 详细规范：[`references/06-post-production.md`](references/06-post-production.md)

### 模块 7：交付与导演决策

**输入**：硬拼接后的成片
**输出**：最终成片（内嵌预览播放器 + 公共访问链接）+ 多平台适配版本 + 封面图

- **成片终审清单**：时长结构 / 画面质量 / 面部与服装一致性 / 音画同步 / 零字幕合规 / 无多余后期处理，完整播放至少两遍（全片无字幕）
- **多平台交付规格**：抖音/快手（9:16）、B站/视频号（16:9 或 9:16）、小红书（9:16 或 3:4）
- **封面图设计**：9:16 / 3:4 / 16:9 多规格，电影海报风（见铁律 19）
- **导演决策手册**：
  - 镜头重设计五法（拆分 / 换景别 / 替代镜头 / 剪影遮挡 / 改变调度）
  - 情绪强化技巧（运镜速度 / 光影 / 提示词）
  - 节奏调整决策（拖沓时 / 仓促时）
  - 视觉风格统一决策
  - 常见创作困境解决方案（角色没灵魂 / 反转没冲击力 / 90 秒讲不完 / AI 感太重）

## 全局铁律

所有模块必须遵守以下铁律（0–25），无一例外：

### 铁律 0：Seedance 2.5 为最高优先级视频生成引擎

- 所有视频生成默认使用 Seedance 2.5，`model_version` 固定为 `seedance_2.5`
- 用户确认的最终提示词**逐字原文透传**，不得改写、润色、精简、翻译
- 生成前必须展示完整确认信息（模型 / 原始 prompt / 时长 / 比例 / 参考素材）
- 时长支持 5-30 秒整数；比例仅支持 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9

### 铁律 1：视频必须以内嵌预览播放器形式交付，交付后自动继续生成下一镜

- 每生成完一个视频，必须以内嵌预览播放器形式展示在对话中
- 用户可直接点击播放按钮预览，无需跳转外部页面；同时附公共访问链接作为补充
- **模块4视频生成阶段内部自动连续生成下一镜，不逐镜暂停等确认**；模块之间（剧本→分镜→提示词→视频→审核→拼接）才需用户确认后推进

### 铁律 2：不含任何去水印内容

- 全技能不包含、不推荐、不指导任何去水印操作
- 涉及水印时，建议使用平台官方无水印导出

### 铁律 3：合规安全

- 所有涉及伤害/死亡/暴力的画面描述必须经过合规替换
- 不出现血腥特写、喷溅血液、断肢、尸体
- 即使 Prompt 已合规，AI 生成仍可能"脑补"违规内容，必须逐镜人工审核

### 铁律 4：物理可行性优先

- 优先级：物理可行性 > 叙事情绪 > 多样性指标
- 室内小空间禁止大远景/鸟瞰/升降，特殊封闭场景禁止横移/拉镜/环绕

### 铁律 5：模块之间自检后展示给用户确认，用户说"可以"再推进

- 用户给出想法或剧本后，按模块1→2→3→4→5→6→7顺序推进，不跳步
- **每完成一个模块，先做完整自检，然后把自检结果展示给用户**
- **用户确认"可以"后，才进入下一个模块**；用户提修改则修改后重新自检
- 模块4视频生成阶段：每镜生成→内嵌预览→自动连续生成下一镜（不逐镜等确认）；整批/整场生成完后统一自检展示，用户确认后进入模块5

### 铁律 6：不编造，不猜测

- 缺少关键信息时补问一个简短问题
- 其他细节自行做合理决定，不把用户拦在连续的选择题前

### 铁律 7：台词与真实环境音写进提示词，不使用 TTS，不混入人为配乐 BGM

- 角色对话、内心独白、画外音、旁白等所有台词，必须直接写进视频生成提示词
- 需要的真实环境音（脚步/雨/风/水流/虫鸣/火焰/衣物摩擦/门轴/马蹄/人群/犬吠等）也写进提示词
- 让 AI 视频模型直接生成带语音和环境音的视频，不使用 TTS（文本转语音）单独合成
- 禁止混入任何人为配乐/BGM（歌曲/情绪配乐/钢琴弦乐 score），以免干扰用户后期

### 铁律 8：生成前必须展示完整提示词，强制图片参考并 @艾特人物

- 每次生成视频前，必须把完整详细的提示词展示给用户确认
- 强制使用图片参考（图生视频模式），不允许纯文字生成
- 提示词中出现用户提供的人物时，必须用 `@图片N` 格式艾特对应的参考图

### 铁律 9：用户提供的人物图片一人一角色，不得重复使用

- 用户提供的每个人物图片只对应剧中一个角色
- 多余角色只用纯文字描述外貌，不使用任何参考图
- 禁止用同一张参考图扮演两个不同角色

### 铁律 10：不用终端，全流程在对话界面完成

- 所有创作、生成、预览、交付均通过对话内完成
- 不要求用户进行任何命令行/终端操作

### 铁律 11：每3-4秒必须有一个信息点，节奏紧凑不空镜

- 每3-4秒必须出现新信息点（镜头变化/对话/物品特写/动作转折）
- 杜绝一个画面定格好几秒没声音没信息
- 逐镜检查：任何3-4秒片段没有新信息推进，必须补镜头或重新切分

### 铁律 12：选题优先社会问题、矛盾冲突、情感痛点

- 题材优先社会现实、矛盾冲突、情感痛点——容易共鸣和传播的方向
- 核心戏剧张力来自反差+矛盾
- 题材不设限，灵活选择最有张力的方向

### 铁律 13：横屏拍摄，全片无字幕

- 默认横屏16:9画幅
- 全片不加字幕，台词通过视频自带语音传达

### 铁律 14：人物通过剧情行动立住，不靠旁白解释

- 通过人物的行动、选择、冲突反应展现性格和背景
- 禁止用旁白/独白直接介绍"他是谁、他什么性格"
- 每个角色出场后通过至少一个具体行动立住

### 铁律 15：每幕自检必须包含角色贴合度和脸崩检查

- 每完成一幕/镜头，检查：角色是否合适（行为符合人设）、脸崩/穿帮/面部一致性
- 逐环检查：提示词→镜头→场景→分镜→脚本→视频
- 自检结果展示给用户确认后才继续

### 铁律 16：站位必须写进提示词，生成前后双轮详细检查

- 两人及以上同框镜头，提示词必须写清站位三要素：左右位置 / 前后远近 / 朝向关系
- 同场景连续多镜左右站位保持一致，除非剧情设计了换位动作
- 生成后逐帧抽 3-5 个关键帧检查：站位/脸崩/肢体/人数/服装/道具/光影/动作，一项不过就重生成

### 铁律 17：以画面和人物表演为主，旁白为辅

- 优先用对话、内心独白、物品特写、反应镜头把信息"演出来"
- 旁白只作点睛补充（开场氛围/结尾点题/时空过渡），禁止用旁白代替叙事、介绍人物背景、念大段说明
- 判断标准：闭上眼睛只听声音能否跟上故事；离开旁白就看不懂就必须改成画面表达

### 铁律 18：开局钩子必须强烈，但必须扎根剧本

- 前 3 秒必须出冲击点（反常画面/炸台词/高反差/悬念问题），制造"为什么？"
- 禁止标题党假钩子：钩子必须是全片核心矛盾的种子，后文能找到答案和呼应
- 钩子后 30 秒内进入正题，结尾回扣开头形成闭环

### 铁律 19：封面必须电影海报级设计

- 专门设计画面而非截图，人物在环境中，氛围感 > 表情夸张
- 标题=片名，4-8 字粗体大字竖排一侧，不挡主体面部
- 封面氛围与正片气质一致，封面人物必须是本片真实角色，不靠标题党

### 铁律 20：成片只做硬拼接，不主动剪辑；全片绝对零字幕（P0 红线）

- 默认镜头按序硬拼接即成片——不裁剪、不调速、不混剪、不加片头片尾卡
- 除非用户明确要求剪辑，否则不进入后期流程；模块6仅允许硬切硬拼接
- 全片零字幕（台词/旁白/解释字卡/剧名卡一律禁止）；唯一例外：纯黑底+居中白字的时空跳转过渡卡（如"二十年后"），单屏 1-2 秒即切走

### 铁律 21：每交付一个用户满意的产物后，主动提醒沉淀经验

- 用户说"可以/满意/不错"后，主动问是否把这次的做法/风格/坑沉淀进技能
- 沉淀通用方法论到 references/，铁律级规则续排到全局铁律，一次性具体情节不存

### 铁律 22：用户没要求时，默认横屏 16:9

- 未指定画幅 = 默认横屏 16:9，不自作主张出竖屏
- 仅用户明确说竖屏/9:16/抖音竖版时才用竖屏；封面按目标平台规格出

### 铁律 23：开头钩子非常强，全片持续爆点，必须跌宕起伏

- 前 3 秒王炸冲击；每 3-5 秒一个新信息点/情绪刺激，不能连续两段平铺
- 情绪曲线必须有高有低，每 30 秒一个小高潮/小反转，严禁中段塌陷
- 结尾回扣钩子或留余味；开头留不住人，后面再好也没人看

### 铁律 24：脸不崩 + 服装同阶段锁死（该锁锁死，该换才换）

- **面部（P0）**：每镜抽帧核对，跨镜与角色锚定参考图一致，无变形/崩坏/换脸；脸崩一律重生成
- **服装同阶段锁死**：同一角色在同一剧情阶段，服装款式/颜色/配饰必须一致，无交代的跳变判不一致
- **换装例外**：仅剧情明确设计换装（换季/入伍/受伤/身份转变/时间跨度等）才允许变化，且必须有镜头或情节交代

### 铁律 25：硬拼接与交付零压缩、零重编码，保持原始画质

- 单镜与成片保持原始分辨率/帧率/码率/编码，不压缩、不降清、不转码降质
- 硬拼接统一用 concat demuxer / `-c copy` 流拷贝，过程不重编码；规格不一致回源头统一导出
- 上传/导出选"原画质/不压缩"，禁止交付通道默认二次压缩

## 快速开始

### 方式一：作为 AI Agent Skill 使用

1. 将本仓库克隆或下载到你的 Skills 目录
2. 在支持 Skill 的 AI Agent 环境中，系统会自动识别 `SKILL.md`
3. 向 AI 描述你的短剧想法，系统会自动识别起始模块并推进

### 方式二：作为创作手册使用

1. 从 [`SKILL.md`](SKILL.md) 开始阅读，了解整体流程和全局铁律 0-25
2. **新项目启动**：先读 [`16-project-playbook.md`](references/16-project-playbook.md)，按项目启动检查清单确认所有参数
3. 根据你当前所处的创作阶段，阅读对应模块的详细规范：
   - 只有想法 → 读 [`01-script-creation.md`](references/01-script-creation.md)（写剧本前必读09爆款公式+10情绪设计）
   - 已有剧本 → 读 [`02-storyboard-design.md`](references/02-storyboard-design.md)
   - 资产准备 → 读15号文件（角色资产/场景锚定/道具规划/服装锁定）
   - 已有分镜 → 读 [`03-prompt-generation.md`](references/03-prompt-generation.md)（写提示词前必查14号视觉术语表；需要胶片画风直接套21号预设）
   - 已有提示词 → 读 [`04-video-production.md`](references/04-video-production.md)
   - 硬拼接交付 → 读 [`06-post-production.md`](references/06-post-production.md)（concat/-c copy 流拷贝命令模板）
   - 出封面 → 读 [`13-cover-design.md`](references/13-cover-design.md)
4. 遇到具体问题时，查阅 [`08-prompt-generation-case-study.md`](references/08-prompt-generation-case-study.md) 中的实战案例

### 从 0 到 1 完整制作流程

```
第0步：项目启动（读16号文件，按检查清单确认参数）
       ↓ 确认参考图/角色/场景/道具/色调/时长/画幅
第1步：提供想法/题材 → 生成剧本（模块1，默认套用09爆款公式+10情绪设计）
       ↓ 自检 → 展示 → 用户确认
第2步：基于剧本 → 生成分镜脚本（模块2）
       ↓ 自检 → 展示 → 用户确认
第2.5步：资产准备（script-asset-master，生成场景空镜图+角色四宫格图+道具图）
       ↓ 锚定角色/场景/道具参考图 + 服装锁定/换装节点
第3步：基于分镜 + 人物参考图 → 生成视频提示词（模块3，人物必须@艾特）
       ↓ 自检 → 展示 → 用户确认
第4步：基于提示词 + 参考图 → 逐镜生成视频片段（模块4，Seedance 2.5引擎，模块内自动连续生成）
       ↓ 每镜内嵌预览 → 整批/整场生成完统一自检（角色/脸崩/站位/服装/信息密度）→ 用户确认
第5步：逐镜质量审核 + 跨镜一致性检查（模块5，面部+服装双锁）
       ↓ 不合格重生成
第6步：镜头按序无损硬拼接（模块6，concat/-c copy 流拷贝，零压缩原画质，全片硬切无转场、零字幕）
       ↓ 拼前统一规格 → ffmpeg concat demuxer 流拷贝 → 拼后音画同步校验
第7步：成片终审 + 多平台交付 + 封面图（模块7，电影海报风封面）
```

## 实战案例

### 《斗罗·六子觉醒》

- **题材**：都市玄幻脑洞（穿越斗罗大陆）
- **规模**：3 集，共 56 镜（第一集 20 镜 + 第二集 16 镜 + 第三集 20 镜）
- **角色**：6 人（用户提供 6 张面部照片，一人一角色不重复）
- **引擎**：Seedance 2.5（第一集）→ Seedance 2.0（第二、三集）
- **核心经验**：提示词越详细生成效果越好；角色必须 @艾特参考图；强制图生视频不用纯文字

完整案例详见 [`references/08-prompt-generation-case-study.md`](references/08-prompt-generation-case-study.md)。

## 适用场景

- ✅ 90 秒竖屏短剧创作与制作
- ✅ 5 分钟精品短剧 / 系列短片
- ✅ AI 动态漫 / 剧情类视频
- ✅ 校园青春、都市言情、古风仙侠、悬疑科幻、玄幻脑洞等题材
- ✅ 基于角色设定图和分镜脚本的逐片段视频生成
- ✅ 需要严格保持角色面部/发型/服装一致性的多片段制作
- ✅ 批量视频生成的调度、审核与版本管理
- ✅ 镜头按序无损硬拼接交付（无人为配乐 BGM、保留真实环境音；后期剪辑/调色/配乐用户自理）

**不适用**：
- ❌ 纯产品广告、纯风景空镜
- ❌ 无角色的抽象概念视频
- ❌ 需要真人出镜的视频
