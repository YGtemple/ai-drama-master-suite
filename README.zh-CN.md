# ai-drama-master-suite

AI 短剧的制作管线——`SKILL.md` 定义方法，`cases/` 是它在四部片子上的应用。

<sub>`SKILL.md` 125 KB · 四份制作记录</sub>

---

## 这是什么

不是「一键生成短剧」的工具，而是一套**约束系统**——用契约、断言和检查清单，把生成过程的不确定性压到可接受的范围内。

```
SKILL.md          方法主体，125 KB
references/       分主题的参考材料
cases/            四部片子的完整记录
```

方法和证据放在一起是刻意的。读完规则，再读应用它之后发生了什么。

## 方法覆盖什么

| 阶段 | 内容 |
|---|---|
| 剧本 | 三层结构（故事 / 隐喻 / 意图）、伏笔物件的 setup→payoff 清单 |
| 资产 | 跨龄面容锚定、道具状态拆分、材质排他 |
| 分镜 | 摄影四参数、配音指令四段式、轴线规则 |
| 视频 | 首图与角色参考分离、逐段确认、废片归档 |

## 四部案例

每一部都有一处特别值得看。

### 《反话》——灵魂相伴题材

**道具连续性表**是重点。一块橡皮跨十场、经历八个状态——借出、赠送、与旧的一起收进铁盒、压在保温桶下、掉落、逐年累积、磨成橡皮头、重置。标注为「不可跳变」。

道具漂移是生成最先出错的地方之一，也是成片前最难发现的。

### 《国家的孩子》——纪录片复刻

35 帧归类到六种景别，算出占比，再从分布反推叙事重心：近景加特写合计 43%，所以资产卡必须把面部细节——高原红、皮肤粗糙度、皱纹深度——写足。

每条结论都带帧号，后续复核可以回到证据。

### 《一会儿》——狗视角第一人称

一份把主观争议转成**人称表**的报告。两轮反馈看似矛盾，直到真正的病灶被点出来：句子没有写明谁在做动作，读者就把「我」贴到了画面上那个正在动的小男孩身上。

这是写法病，不是视角选错了。人称表随后为全片固定了每个代词的唯一指代。

### 《凝视的接力》——代际凝视

25 部经典影片 × 5 种叙事手法，做成索引。其中一个评估维度是 **AI 可行性**——某个方向可以在传播力上拿高分，可行性却很低，因为高空脚手架是生成的高风险画面。

好想法渲染不出来，还是零。

## 案例里反复出现的做法

| 做法 | 解决的问题 |
|---|---|
| 主锚定 + 跨龄重复骨相特征 | AI 换脸 |
| 固定 seed，压低风格化 / 怪异度 / 多样性 | 跨镜不一致 |
| ASCII 俯视图 + 轴线规则 | 越轴、空间错乱 |
| 道具连续性表追踪每次状态变化 | 道具在剪辑点之间变形 |
| 每组分镜都重复「不得重建房间」 | 同一个地方每次长得不一样 |
| 材质排他句（「不是石头」） | 白色物体被渲染成大理石 |
| 配音指令四段式 | 角色声音跨镜漂移 |
| 全片唯一人称表 | 指代歧义导致返工 |
| 影片 × 手法矩阵 | 找参考片时没有起点 |
| 版本修正记录 | 同一个错犯第二次 |

## 立场

两句话出现在不同的文档里，意思是一样的：

> 不追求全自动。分镜与角色一致性这两个环节仍需人工确认——全自动流程恰恰在这两步失败，返工成本比手工检查更高。

> 用户认可才做下一个。
