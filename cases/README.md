## 每部片子最值得看的一处

### 《反话》· 道具连续性表

白橡皮一条线跨 10 场，经历八个状态：

```
场2 半旧橡皮借她 → 场4 崭新橡皮相赠、与旧橡皮并放铁皮盒
→ 场5 新橡皮压保温桶 → 场6 新橡皮落地、滚上白天斑马线
→ 场8–9 盒中橡皮逐年增多 → 场10 临终掌中只剩「橡皮头」
→ 彼岸他递来一块崭新橡皮
```

标注「不可跳变」。AI 生成最容易出问题的地方就是上一镜还在口袋里、下一镜就变新了。

### 《国家的孩子》· 景别统计反推叙事重心

35 帧归类到六种景别，算出占比：

| 景别 | 占比 |
|---|---|
| 近景/特写（CU） | 31.4% |
| 全景/远景（WS） | 20.0% |
| 中近景（MCU） | 14.3% |
| 中景（MS） | 14.3% |
| 面部大特写（ECU） | 11.4% |

**结论**：近景+特写合计 43%，所以资产卡必须把面部细节（高原红、皮肤粗糙度、皱纹深度）写足。

### 《一会儿》· 把主观争议转成人称表

用户两次反馈看似矛盾：J02 接受「我是狗」、J03 却炸毛。报告不争论对错，直接指出病根：

> 句子没写清谁在做动作，大脑自动把「我」贴到了画面上正在动的小男孩身上。**这是写法病，不是视角选错了。**

然后给出全片唯一人称表：

| 词 | 固定指代 | 出现场合 |
|---|---|---|
| 我 | 阿墩（狗） | 仅限画外音/内心独白 |
| 他 | 小宇（人） | 狗的画外音里指男孩 |
| 你 | 小宇（人） | 仅限狗对小宇的呼唤句 |
| 它 | 阿墩（狗） | 仅限人类现场台词中称呼狗 |

### 《凝视的接力》· 评估维度含 AI 可行性

25 部经典影片 × 5 种手法的索引矩阵。评估不只看艺术价值，还看**能不能生成出来**：

方向②《高处的人》爆款潜力 ★★★★★ 但可行性 ★★★ —— 因为「高空脚手架是 AI 高风险画面，易穿模」。

创意再好，AI 生成不出来也是零。

## 反复出现的做法

| 做法 | 解决的问题 |
|---|---|
| 主锚定 + 跨龄重复骨相特征 | AI 换脸 |
| 固定 seed + 风格化/怪异度/多样性全压低 | 跨镜不一致 |
| ASCII 俯视图 + 轴线规则 | 越轴、空间错乱 |
| 道具连续性表追踪每状态跳变 | 道具凭空变形 |
| 「不得重建房间」重复声明 | 同一场景生成不同样 |
| 材质排他句（「不是大理石」） | 静物被生成成石头 |
| 配音指令四段式 | 角色声音跨镜不一致 |
| 全片唯一人称表 | 视角歧义引发返工 |
| 案例 × 手法矩阵 | 找参考片没头绪 |
| 版本修正记录 | 同一个坑反复踩 |
