# 后期合成规范

## 概述

将审核通过的多段AI视频素材剪辑合成为完整的短剧成片。后期合成不是简单拼接——它决定了最终的节奏、情绪、沉浸感和专业度。

**核心原则**：AI生成的素材是raw material，后期合成才是导演的最终表达。同样的素材，不同的剪辑节奏、音效、调色，可以产出完全不同水准的成片。

---

## 一、剪辑与节奏

### 1.1 基础剪辑流程

1. **按分镜时间码搭建时间线**：将所有终选镜头按镜号顺序放入时间线
2. **粗剪**：按分镜标注的时长裁切每镜，拼接成粗剪版
3. **精剪**：逐镜调整入点/出点，优化动作连贯性和节奏
4. **总时长校验**：严格控制在目标时长（90秒±2秒 或 5分钟±5秒）

### 1.2 入点/出点选择

**入点（镜头开始）**：
- 动作镜头：在动作即将开始前1-2帧切入（不要等动作已经开始了才切）
- 表情镜头：在表情变化发生前切入（让观众看到表情变化的过程）
- 反应镜头：在触发反应的动作/台词之后立即切入（反应要及时）

**出点（镜头结束）**：
- 动作镜头：在动作完成后1-2帧切出（让观众看到动作结果）
- 台词镜头：在台词说完后停留0.3-0.5秒再切（给观众消化时间）
- 情绪镜头：在情绪峰值后停留0.5秒再切（让情绪沉淀）
- 悬念镜头：在最关键的瞬间切出（卡点，不要把答案给出来）

### 1.3 节奏与情绪曲线匹配

| 幕 | 情绪 | 剪辑节奏 | 镜头时长 | 转场 |
|---|---|---|---|---|
| 开场强冲击 | 紧张/悬念 | 快切，快速建立冲突 | 1-3秒/镜 | 硬切 |
| 核心冲突推进 | 升级/对抗 | 中等节奏，随情绪递进加速 | 3-6秒/镜 | 硬切 |
| 反转爆发 | 震惊/爽感 | 最快节奏，高潮处极快切 | 0.5-3秒/镜 | 硬切 |
| 结尾强悬念 | 悬疑/期待 | 突然放慢，留白 | 3-8秒/镜 | 硬切 |

**节奏变化技巧**：
- **加速**：情绪升级段，逐镜缩短时长（5秒→4秒→3秒→2秒），制造紧迫感
- **减速**：情绪爆发后，突然用一个长镜头（5-8秒）放慢，让观众消化
- **骤停**：反转时刻，所有运动和声音突然停止0.5秒，然后爆发
- **呼吸感**：连续快切后插入0.5-1秒停顿镜（角色喘息/空镜），给观众喘息

### 1.4 动作连贯性剪辑（Match Cut）

AI生成的镜头之间动作可能不连贯，用以下技巧修复：
- **动作匹配**：前一镜动作结束位置 = 后一镜动作开始位置
- **视线匹配**：前一镜角色看向画外，后一镜切到角色看到的东西
- **位置匹配**：前一镜主体在画面左侧，后一镜主体也在左侧
- **音效桥接**：前一镜的动作音效延续到后一镜，掩盖视觉不连贯

## 二、转场设计

### 2.1 转场使用原则

- **全片仅使用硬切/硬拼接**：所有镜头之间一律直接硬切，干净利落，0帧切换
- **禁止一切非硬切转场特效**：不使用淡入淡出、闪白、闪黑、叠化、匹配切、旋转、缩放、翻页等任何转场特效
- **转场节奏靠剪辑点控制**：用入点/出点选择、镜头时长、动作切点来控制节奏，不靠转场特效

### 2.2 转场类型与使用场景

| 转场类型 | 效果 | 使用场景 | 时长 |
|---|---|---|---|
| 硬切 | 直接切换 | 全片所有镜头之间，唯一允许的转场方式 | 0帧 |

> 说明：本技能不使用淡入淡出、闪白、闪黑、叠化、匹配切等任何非硬切转场。片头到第一镜、幕间切换、反转时刻、结尾悬念卡之间，也一律用硬切（或硬切至黑场）。

### 2.3 关键节点转场设计

- **开场**：片头（2-3秒剧名）→ 硬切 → 第一镜
- **幕间切换**：第一幕→第二幕、第二幕→第三幕（反转前）一律硬切
- **反转时刻**：反转镜直接硬切切入，配合音效冲击（不加闪黑）
- **结尾悬念**：最后一镜在悬念最高点 → 硬切至黑 → 悬念卡

## 三、音效与配乐

### 3.0 两种音效模式（项目启动时确认）

**默认模式：四层音效（台词 > 动效 > 环境 > BGM）**
适用于大多数项目，用BGM引导情绪走向，是本规范的默认配置。

**无BGM模式：三层音效（台词 > 动效 > 环境）**
当项目约束不加BGM（用户明确要求、题材不需要配乐、或平台风格要求）时启用。此时用环境音和动效音的层次变化来引导情绪，用静音段和骤停制造节奏。

**无BGM模式下的情绪引导技巧：**
- **环境音渐变**：紧张时环境音减弱/心跳声增强；放松时环境音回归（远处人声、车流）
- **动效音强化**：关键动作加低频冲击（door slam、物品掉落加重低音），用音效替代BGM的情绪冲击
- **静音留白**：反转前0.5秒全静音 → 反转镜只有台词+一个重击音效 → 后续环境音缓缓回归
- **节奏靠切镜频率**：无BGM时，情绪紧张感完全靠剪辑节奏（快切/慢切）和声音设计（动效密度）来传达，不靠音乐推
- **参考案例**：纪录片风格、写实悬疑片、生活流短片常用无BGM模式，靠环境声和动效营造真实感

> 启动新项目时，在项目启动检查清单（见16号文件）中确认BGM模式：默认四层，还是无BGM三层。

### 3.1 音效四层结构

```
第一层：台词（视频自带语音）—— 最优先，必须清晰可辨
第二层：动效音（Foley）—— 关键动作的音效
第三层：环境音（Ambience）—— 场景氛围音
第四层：BGM（配乐）—— 情绪引导，台词出现时自动压低
```

**重要：台词/语音来自视频生成时提示词中写入的台词，由AI视频模型直接生成，不需要TTS单独合成。** 后期只需调整台词音量和混音，不需要额外导入语音文件。

**音量层级**（相对值）：
- 台词：-6dB ~ -3dB（最响，永远是最优先的音轨）
- 动效音：-12dB ~ -8dB
- 环境音：-18dB ~ -14dB
- BGM：-20dB ~ -16dB（无台词时），-28dB ~ -24dB（有台词时压低）

### 3.2 动效音设计

**必须加动效的动作**：
- 脚步声（不同地面材质：木地板/水泥地/地毯/水面）
- 开门/关门声
- 物品放置/拿起声
- 打斗声（拳风/击中/撞击）
- 衣物摩擦声（特写动作时）
- 呼吸声（紧张/情绪爆发时）
- 电子设备声（手机震动/屏幕点击/提示音）

**动效音技巧**：
- 动效音要与画面动作精确同步（差2帧以上就会被察觉）
- 关键动作的动效音可以略夸张，增强冲击感
- 连续动作的动效音要有层次（打斗：拳风→击中→身体撞墙→落地）
- 反转时刻的动效音可以骤停（所有声音突然停止0.3秒），增强震惊感

### 3.3 环境音设计

**常见场景环境音**：
- 室内办公室：空调低鸣、键盘声（远处）、日光灯电流声
- 街道：车流声、人声嘈杂、风
- 夜晚室内：时钟滴答、远处虫鸣、寂静感
- 水下：水流声、muffled声音、气泡
- 雨天：雨声、雷声、水滴

**环境音技巧**：
- 环境音要"在场但不抢戏"——观众潜意识感受到氛围，但不会注意到环境音本身
- 场景切换时环境音要跟着变
- 紧张场景可以去掉环境音（突然安静），制造压迫感
- 情绪爆发后可以用环境音回归，表示"回到现实"

### 3.4 BGM选曲与混音

**四幕BGM逻辑**：

| 幕 | 情绪 | BGM风格 | 乐器 |
|---|---|---|---|
| 开场强冲击 | 悬念/紧张 | 低频脉冲+不和谐音 | 低音提琴、电子脉冲、钢琴单音 |
| 核心冲突推进 | 升级/对抗 | 渐进式弦乐+打击乐 | 弦乐组、定音鼓、电子节拍 |
| 反转爆发 | 震惊/爽感 | 爆发式全奏+音效冲击 | 全乐队、铜管、打击乐+电子低音 |
| 结尾强悬念 | 悬疑/期待 | 留白式单音+回响 | 钢琴单音、弦乐长音、电子回响 |

**BGM混音技巧**：
- **台词闪避（Ducking）**：有台词时BGM自动压低6-10dB，台词结束后恢复
- **情绪同步**：BGM的高潮点必须与画面反转点精确同步
- **骤停技巧**：反转前0.5秒BGM骤停 → 反转镜无BGM（只有动效）→ 0.5秒后BGM爆发
- **首尾呼应**：开场BGM的主题旋律在结尾悬念处再现（变奏/放慢），形成闭环
- **不要用有歌词的BGM**：歌词会与台词冲突，纯音乐优先

### 3.5 音效冲击点设计

- **反转揭示**：低音boom（30-60Hz）+ 骤停 + 0.3秒寂静 + 爆发
- **打斗击中**：低频撞击 + 高频脆响
- **关键台词**：台词出现时BGM压低，动效音减弱，突出人声
- **悬念卡点**：最后一镜切出时加悬疑音（上升音/不和谐和弦/心跳声）
- **场景跳转**：硬切直接切入新场景，配合音效桥接（whoosh/上升音/低音boom）辅助衔接，**禁止使用闪白/闪黑/叠化等任何转场特效**

## 五、调色与视觉统一

### 5.1 全片调色原则

- **统一LUT**：全片应用同一个基础LUT，确保跨镜色彩一致
- **按情绪段微调**：在统一LUT基础上，按四幕情绪做微调
- **不逐镜乱调**：每个镜头单独调色会导致跨镜色彩跳跃，必须统一基调

### 5.2 四幕色调设计

| 幕 | 情绪 | 色调倾向 | 调色参数 |
|---|---|---|---|
| 开场强冲击 | 悬念/紧张 | 冷色调，低饱和，高对比 | 色温偏蓝，饱和度-10%，对比度+15% |
| 核心冲突推进 | 升级/对抗 | 中性偏冷，逐渐加对比 | 色温中性，对比度逐镜+5% |
| 反转爆发 | 震惊/爽感 | 高对比，饱和度提升 | 对比度+25%，饱和度+15% |
| 结尾强悬念 | 悬疑/期待 | 冷色调，暗角，低亮度 | 色温偏蓝，亮度-10%，加暗角 |

### 5.3 跨镜色彩统一技巧

- **同场景镜头**：必须用完全相同的调色参数（复制粘贴调色属性）
- **相邻镜头**：检查肤色是否一致（AI生成的肤色可能有偏差，统一肤色是重点）
- **光影不一致**：调色可以部分缓解（统一色温/亮度），但差异过大必须重生成
- **加暗角**：全片加轻微暗角（-10%~-15%），统一画面感，引导视觉重心到中心

### 5.4 画质增强

- **锐化**：全片加轻微锐化（+10%~+15%），提升清晰度感
- **降噪**：如果有明显噪点，加降噪（但不要过度，否则会模糊）
- **稳定**：如果镜头有不自然抖动，加稳定效果（但AI生成的抖动有时是"运动感"，不要全部稳定掉）

## 六、片头片尾设计

### 6.1 片头

- **时长**：2-3秒（不要太长，短剧要快速进入正片）
- **内容**：剧名（大字）+ 副标题/集数（小字）
- **风格**：与全片视觉风格一致
- **转场**：片头 → 硬切 → 第一镜

### 6.2 结尾悬念卡

**出现时机**：最后一镜硬切至黑后
**内容**：核心悬念句 + "未完待续"或"下集揭晓" + 追更引导
**时长**：2-3秒
**音效**：悬疑音（上升音/心跳声/不和谐和弦），戛然而止

### 6.3 水印与标识

- 如果需要加账号水印，放在角落（不影响画面），透明度50%
- 不要在画面中央加水印
- 水印不要遮挡关键画面
- **本技能不含任何去水印内容**

## 七、后期合成执行流程

```
素材准备（所有终选镜头 + 锚定图 + 分镜表，视频自带角色语音）
    │
    ▼
粗剪（按分镜拼接，校验总时长）
    │
    ▼
精剪（调整入点/出点，优化节奏和动作连贯）
    │
    ▼
转场设计（全片硬切/硬拼接，无任何转场特效）
    │
    ▼
调色（统一LUT + 四幕微调 + 跨镜色彩统一）
    │
    ▼
音效设计（台词音量调整 + 动效音 + 环境音 + BGM + 冲击点 + BGM闪避）
    │
    ▼
片头片尾（剧名片头 + 悬念卡结尾）
    │
    ▼
成片终审（完整播放，检查所有维度，确认有声音有对话）
    │
    ▼
导出交付（按目标平台规格导出，附公共访问链接）
```

## 七补、AI生成素材的后期特殊性

AI生成的视频素材和真人拍摄素材在后期处理上有本质区别，必须注意以下几点：

### A. 语音来自视频本身，不需要导入语音文件
- AI生成时已在提示词中写入台词，视频自带角色对话语音
- 后期不需要单独导入TTS语音文件，不需要对齐口型
- 如果某镜语音不清晰/语速不对，应回到模块4调整提示词重新生成，而不是后期配音补救

### B. AI生成的视频通常没有环境音和动效音
- 除非提示词中明确描述了声音（如"脚步声""雨声"），AI生成的视频音频轨通常只有台词
- **环境音和动效音必须在后期补充**：这是AI短剧后期的必做项，不是可选项
- 补充方式：用ffmpeg将环境音/动效音轨叠加到视频上（见下方工具链章节）

### C. 调色是必须步骤，不是可选步骤
- AI跨镜生成的视频，色彩、色温、亮度几乎不可能自动一致
- **全片调色统一是AI短剧后期的强制步骤**：不调色的成片会出现"每镜颜色都不一样"的拼接感
- 同场景镜头必须应用完全相同的调色参数（复制ffmpeg滤镜链）

### D. 轻微动作卡顿可用加速掩盖
- AI生成的视频偶有轻微动作卡顿/不自然的帧
- 如果卡顿不严重，可对该镜做1.05-1.1倍速加速（ffmpeg setpts滤镜），掩盖卡顿感
- 加速同时音频 pitch 保持不变（asetrate + atempo 配合）
- 如果卡顿严重（超过1秒），不要用后期加速掩盖，回到模块4重新生成

### E. 分辨率/帧率可能不一致
- 批量生成的视频可能分辨率或帧率有微小差异
- 拼接前统一缩放到目标分辨率和帧率（ffmpeg scale + fps滤镜）

## 八、后期操作工具链

> 以下所有操作通过Bash工具执行ffmpeg命令完成，用户无需手动操作。所有命令模板可直接复制使用。

### 8.1 视频拼接（硬切拼接）

**步骤1：创建文件列表 filelist.txt**

按镜头顺序，每行一个文件：
```
file 'shot01.mp4'
file 'shot02.mp4'
file 'shot03.mp4'
```

**步骤2：拼接（直接copy，不重编码，速度最快）**
```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output_concat.mp4
```
- `-safe 0`：允许使用相对路径
- `-c copy`：直接复制流，不重新编码，秒级完成
- 如果各镜头分辨率/编码不一致，`-c copy` 会失败，改用重新编码模式：
```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c:v libx264 -crf 18 -c:a aac -b:a 192k output_concat.mp4
```

### 8.2 统一分辨率和帧率

拼接前统一所有素材规格：
```bash
ffmpeg -i input.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=24" -c:a copy output.mp4
```
- `scale=1920:1080`：缩放到目标分辨率（横屏1080p）
- `pad=...`：黑边填充保持比例（避免拉伸变形）
- `fps=24`：统一帧率为24fps（电影感）

### 8.3 调色（统一LUT + 四幕微调）

**基础统一调色（全片应用）：**
```bash
ffmpeg -i input.mp4 -vf "eq=brightness=0.05:contrast=1.2:saturation=0.9,colorbalance=rs=0.05:gs=0:bs=-0.05" -c:a copy output_graded.mp4
```
- `eq=brightness=0.05`：亮度微调（-1.0~1.0，0为默认）
- `contrast=1.2`：对比度（1.0为默认，1.2增强对比）
- `saturation=0.9`：饱和度（1.0为默认，0.9略降饱和=电影感）
- `colorbalance=rs=0.05:bs=-0.05`：色彩平衡（红偏+、蓝偏-=暖调；反过来=冷调）

**冷调场景示例（悬疑/夜晚）：**
```bash
ffmpeg -i input.mp4 -vf "eq=brightness=-0.03:contrast=1.25:saturation=0.85,colorbalance=rs=-0.05:bs=0.08" -c:a copy output_cold.mp4
```

**暖调场景示例（黄昏/室内暖光）：**
```bash
ffmpeg -i input.mp4 -vf "eq=brightness=0.03:contrast=1.15:saturation=0.95,colorbalance=rs=0.08:bs=-0.05" -c:a copy output_warm.mp4
```

**加暗角（全片统一）：**
```bash
ffmpeg -i input.mp4 -vf "vignette=PI/5" -c:a copy output_vignette.mp4
```
- `vignette=PI/5`：暗角强度（PI/4最强，PI/5为轻微，推荐PI/6~PI/5）

### 8.4 音量调整

**调整视频原生台词音量：**
```bash
ffmpeg -i input.mp4 -af "volume=-3dB" -c:v copy output_loud.mp4
```
- `volume=-3dB`：降低3dB；`volume=2dB`：提升2dB
- 台词目标：-6dB ~ -3dB

### 8.5 音频混合（叠加环境音/动效音/BGM）

**将BGM叠加到视频上（BGM音量压低，台词为主）：**
```bash
ffmpeg -i video_with_voice.mp4 -i bgm.mp3 -filter_complex \
"[1:a]volume=-20dB[bgm];[0:a][bgm]amix=inputs=2:duration=first:dropout_transition=2[aout]" \
-map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k output_with_bgm.mp4
```
- `[1:a]volume=-20dB`：BGM音量压到-20dB（无台词时）
- `amix=inputs=2`：混合两条音轨
- `duration=first`：以第一条（视频原声）时长为准
- 有台词时建议BGM再压低6-10dB（手动调整volume值）

**叠加环境音（持续底噪）：**
```bash
ffmpeg -i video.mp4 -i ambience.mp3 -filter_complex \
"[2:a]volume=-18dB[amb];[0:a][amb]amix=inputs=2:duration=first[aout]" \
-map 0:v -map "[aout]" -c:v copy -c:a aac output.mp4
```

**多层音效混合（台词+动效+环境+BGM四层）：**
```bash
ffmpeg -i video.mp4 -i foley.wav -i ambience.mp3 -i bgm.mp3 -filter_complex \
"[1:a]volume=-10dB[foley];[2:a]volume=-16dB[amb];[3:a]volume=-20dB[bgm];\
[0:a][foley][amb][bgm]amix=inputs=4:duration=first[aout]" \
-map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k output_final.mp4
```
- 四层音量从高到低：台词(-6~-3dB) > 动效(-10dB) > 环境(-16dB) > BGM(-20dB)

### 8.6 片头片尾静态图生成与合成

**片头图生成**：用image_gen工具生成2-3秒静态剧名片头图，然后合成视频：
```bash
ffmpeg -loop 1 -i title_card.png -f lavari -i anullsrc=r=44100:cl=stereo \
-t 3 -vf "scale=1920:1080" -c:v libx264 -tune stillimage -c:a aac -shortest title_clip.mp4
```
- `-loop 1 -i title_card.png`：静态图循环
- `-t 3`：持续3秒
- 片尾悬念卡同理，换一张图即可

**片头+正片+片尾拼接**：将title_clip.mp4、正片、end_card.mp4按顺序加入filelist.txt后concat拼接。

### 8.7 加速掩盖轻微卡顿

```bash
ffmpeg -i input.mp4 -filter:v "setpts=PTS/1.08" -filter:a "atempo=1.08" output_fast.mp4
```
- `setpts=PTS/1.08`：视频加速1.08倍
- `atempo=1.08`：音频同步加速（保持pitch不变）
- 适用范围：1.05x~1.1x，超过1.1x会明显察觉

### 8.8 导出与预览

**最终导出（H.264，高质量，适合上传平台）：**
```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 18 -preset medium -c:a aac -b:a 192k -movflags +faststart final_output.mp4
```
- `-crf 18`：高质量（18-23，越小越高质量越大）
- `-movflags +faststart`：优化网络播放（边下边播）

## 九、后期合成自检门

- [ ] 总时长与剧本规划时长偏差≤10%？
- [ ] 剪辑节奏是否匹配四幕情绪曲线？
- [ ] 入点/出点是否准确（动作不截断、台词有消化时间）？
- [ ] 动作连贯性是否检查（Match Cut）？
- [ ] 是否全部使用硬切（无任何转场特效）？
- [ ] **视频中角色对话语音是否清晰可辨（来自提示词中写入的台词）？**
- [ ] **有台词的镜头是否都有语音（无"只有BGM没有对话"的镜头）？**
- [ ] **台词音量是否统一（-6~-3dB），高于BGM和动效音？**
- [ ] 音效四层（台词/动效/环境/BGM）音量层级是否正确？
- [ ] **无BGM模式下（如启用）：是否用环境音渐变+动效强化+静音留白替代了BGM情绪引导？**
- [ ] BGM在台词出现时是否自动压低（Ducking）？
- [ ] BGM高潮点是否与画面反转点同步？
- [ ] 动效音是否与画面动作精确同步？
- [ ] **AI素材特殊性：环境音/动效音是否已补充（AI生成视频通常不带环境声）？**
- [ ] **AI素材特殊性：全片调色是否统一（跨镜色彩是否一致，肤色是否统一）？**
- [ ] **AI素材特殊性：动作卡顿处是否已用1.05-1.1x加速掩盖？**
- [ ] **AI素材特殊性：各镜头分辨率/帧率是否已统一？**
- [ ] 全片调色是否统一？跨镜色彩是否一致？
- [ ] 肤色是否全镜一致？
- [ ] 片头片尾是否设计完成？
- [ ] 成片是否完整播放检查过（无黑帧/跳帧/音画不同步，**有声音有对话**）？
- [ ] **最终成片是否以内嵌预览播放器形式交付？**
- [ ] **最终成片是否同时附了公共访问链接？**
