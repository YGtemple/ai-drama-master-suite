# 13. 封面设计规范（电影海报风）

> 本文件基于用户指定的标杆账号封面风格拆解。每次出封面前必须读这个文件。

---

## 一、标杆风格核心原则

**封面不是截图加字，是一张电影海报。**

观众刷到封面时，应该像在电影院看到海报一样——被画面氛围吸引，被片名勾起好奇，想点进去看。

## 三、设计规则（从上面总结）

### 1. 构图规则

- **人物在画面中下部或中间，占画面1/2到2/3**，上方或一侧留空给标题
- **中景/全景为主**：拍人的全身或大半身，不要大脸特写怼镜头
- **优先背影、侧脸、低头**：人物不需要看镜头，情绪靠场景传
- **人物穿旧衣服、有生活质感**：不要精致妆造，要真实感
- **画面必须有一个"环境主角"**：路、窗、门、面摊、抽屉、路灯、雪——环境本身就在讲故事

### 2. 标题文字规则（主推荐风格：左侧竖排巨大毛笔字）

> **主页封面格子很小，字小了看不清。以下是经过主页实测验证的主推荐版式，每次出封面默认用这个。**

**A. 主推荐版式：左侧竖排巨大白色毛笔书法字**
- **字体必须是毛笔书法体**：要有笔锋、飞白、手写感、粗细变化，像"茶汤""第100条语音""薄银"那种——**不是普通粗黑体、不是综艺体、不是宋体**
- **字号巨大**：标题占画面宽度1/3到1/2，占画面高度2/3以上，在主页小格子里一眼就能看清
- **位置：竖排靠左**，从上到下排列，字顶到画面上方1/10处，字底到画面中下部
- **颜色：白色**（暗底上），不要加描边、不要加阴影、不要花字
- **片名长度**：2-6字最佳（"茶汤""招娣""薄银""栖野""第100条语音"），字越多字号越小，尽量短
- **不挡人物面部和关键道具**：人物放在画面右侧或右下，让开左侧字区

**B. 为什么是这个版式（不要改）**
- 主页封面是小格子，横排大字会挡画面主体
- 顶部小字（像"招娣"那种）在小格子里根本看不清
- 右侧竖排也可以，但左侧是首选（视觉从左往右读）
- 毛笔书法字自带电影感和人文气，比黑体高级

**C. 其他版式（备选，不常用）**
- 横排顶部居中：只适合片名≤3字、且顶部是空场景时
- 横排底部：尽量不用，会被平台UI挡住
- ❌ 不要用：顶部小字+多行说明文字（在小格子里看不清）、花字贴纸、渐变字、描边字

**D. 副标题（可选，尽量不要）**
- 主页小格子里副标题根本看不清，默认不加
- 如果要加，极小字紧贴主标题旁边，补充情绪，可有可无

### 3. 色调规则

- **电影感冷暖对比**：暗部冷蓝/深蓝，亮部暖黄/橙
- **常见配色方案**：
  - 深夜+路灯黄（雨夜、门口、街道）
  - 黄昏夕阳+远山（归途、离别）
  - 煤油灯+暗褐（怀旧、秘密）
  - 雪+暖黄蒸汽（冬日、食物）
- **整体偏暗**：不要亮堂堂的，暗调才有电影感

### 4. 场景符号库（什么情绪配什么场景）

| 情绪/主题 | 推荐场景元素 |
|---|---|
| 等待/回家 | 雨夜门口、路灯下、村口、车站 |
| 思念/回忆 | 旧抽屉、煤油灯、老照片、旧物、窗 |
| 孤独/归途 | 山间土路、远山、一个人走路、黄昏 |
| 温暖/善意 | 面摊、馒头店、热汤、蒸笼冒气 |
| 错过/遗憾 | 背对背、两个人剪影、黄昏湖面 |
| 亲情/母爱 | 母亲站门口、递碗、牵手、老屋 |
| 成长/兄弟 | 一群孩子、旧楼、学校 |

### 5. 禁止事项

- ❌ 大脸特写怼镜头（我们之前做的那版是错的）
- ❌ 标题写成公众号说明文（"她竟然……""结果……"）
- ❌ 亮堂堂的、平光、没有光影
- ❌ 人物看镜头摆拍感
- ❌ 花哨字体、花字、贴纸

## 四、封面提示词模板

生成封面图时用这个结构：

```
竖屏9:16，电影海报质感。[时间/天气]，[场景描述]，[人物在画面右侧/右下，背影或侧脸，中远景]。[前景必须有一个关键道具特写，占画面下部]。[光源和色调：冷蓝环境+一点暖光]。画面左侧竖排巨大白色毛笔书法字"[片名]"，字体苍劲有力，有飞白笔锋，占画面宽度1/3到1/2，不遮挡人物。整体低饱和度电影色调，空气透视层次（近实远虚、远景带雾），氛围感强。
```

### 模板示例（茶汤风格——主推荐）

```
竖屏9:16，电影海报质感。清晨江边石阶，晨雾弥漫，一位白发老人穿着旧棉袄蹲在石阶上，背影，面朝江水。前景石阶上放着两个粗陶碗，碗里热茶冒着白色蒸汽。冷蓝色调，江面有薄雾，远处石阶和船隐在雾里。画面左侧竖排巨大白色毛笔书法字"茶汤"，字体苍劲有力有飞白，占左半边画面，不遮挡老人。整体低饱和度，冷蓝晨雾+暖茶热气，空气透视层次，电影感。
```

### 模板示例（第100条语音风格——主推荐）

```
竖屏9:16，电影海报质感。昏暗老房间，黄昏窗外透进冷蓝色天光，一个年轻女人坐在床边低头看手机，侧脸。床边旧桌上摆着一个黑相框，相框里是老人遗像。画面左侧竖排巨大白色毛笔书法字"第100条语音"，字体苍劲有力有飞白，占左半边画面，不遮挡女人。整体低饱和度，暗部冷蓝，窗外黄昏光，电影感。
```

### 4.1 多规格封面输出（从同一设计派生）

一张封面设计，派生三种平台规格，**核心构图和氛围保持不变**，仅调整安全区和文字位置：

| 平台 | 比例 | 尺寸 | 调整要点 |
|---|---|---|---|
| 抖音/快手 | 9:16 | 1080×1920 | 竖版主规格。人物在中下部，标题竖排在左/右侧。上下留出平台UI安全区（顶部各留15%空白，底部留20%） |
| B站/视频号 | 16:9 | 1920×1080 | 横版。从竖版底图向左右扩展场景内容（路向两边延伸、天空加宽），标题改为横排顶部居中。人物在画面中下部 |
| 小红书 | 3:4 | 1080×1440 | 介于竖版和横版之间。人物占画面比例略大，标题可横排顶部或竖排一侧。顶部留出标题区 |

**派生方法：**
1. 先做9:16竖版主封面（信息最全、构图最完整）
2. 横版16:9：用image_gen重新生成时，把场景描述改为横版构图（人物居中偏下，左右环境延展），标题改为横排顶部
3. 3:4小红书：基于竖版构图微调，人物略放大，标题位置根据留白调整
4. **不要直接裁剪竖版图当横版用**——裁剪会切掉环境氛围，失去电影感

### 4.2 封面生成执行步骤

```
第1步：确定封面核心画面
  │  从正片中选一个最有氛围感的场景+人物组合
  │  要求：同场景同人物，能代表全片情绪基调
  │
  ▼
第2步：按本文件第四节模板写封面提示词
  │  必带：低饱和度 + 空气透视 + 电影级光影
  │  标题=片名（4-8字），粗体，不挡人物
  │
  ▼
第3步：用image_gen工具生成封面底图（默认9:16）
  │
  ▼
第4步：检查电影海报质感（对照第六节自检清单）
  │  像不像电影海报？还是截图加字？
  │
  ├─ 不合格 → 调整提示词（补光影/加环境符号/改标题位置）→ 重新生成
  │
  └─ 合格 ↓
第5步：多规格派生
  │  基于已确认的竖版设计，生成16:9横版和3:4小红书版
  │
  ▼
第6步：交付封面（9:16主版 + 16:9横版 + 3:4小红书版）
```

## 五、高级感视觉关键词（提示词必带）

以下两个词是"显高级"的关键，**每次生成封面/视频提示词都要带上**：

### 1. 低饱和度（Desaturated / Muted）
- 画面颜色不鲜艳、偏灰、克制
- 去掉数码味/综艺感，显电影感
- **提示词写法**："低饱和度色调""色彩克制""去饱和电影调色""muted colors"
- **不要写**："鲜艳""色彩丰富""高饱和"

### 2. 空气介质透视 / 大气透视（Atmospheric Perspective）
- 前景清晰深暗，中景过渡，远景被雾/水汽笼罩变浅变蓝变模糊
- 让二维画面有三层空间深度，不扁平
- **提示词写法**："空气透视层次""近实远虚""远景带薄雾""前景深远景浅""atmospheric haze"
- **实现方式**：场景里加雾、烟、雨、灰尘、水汽；用逆光/侧逆光让空气可见

### 其他加分词
- **浅景深**（shallow depth of field）：人物清晰，背景虚化
- **电影级光影**（cinematic lighting）
- **胶片质感**（film grain / analog look）
- **暗调**（dark moody tone）

## 六、自检清单

出完封面逐条过：

- [ ] 像不像一张电影海报？（不是截图加字）
- [ ] **标题是不是毛笔书法体？（有笔锋飞白，不是普通粗黑体/综艺体）**
- [ ] **标题是不是左侧竖排巨大字？（占画面1/3到1/2宽度，主页小格子里一眼能看清）**
- [ ] **标题字号够不够大？（缩到手机主页格子大小还能看清吗？看不清就是字太小）**
- [ ] 标题像不像电影名？（2-6字最佳，不是说明文）
- [ ] 人物是中景/全景，在画面右侧？（让开左侧字区，不是大脸特写）
- [ ] **前景有没有关键道具特写？（茶汤碗/银镯子/相框这种，占画面下部）**
- [ ] 色调有没有冷暖对比？暗调电影感？
- [ ] **是否低饱和度？（不鲜艳、不数码味）**
- [ ] **是否有空气透视层次？（近实远虚、远景带雾、有空间深度）**
- [ ] 环境场景有没有在讲故事？（路/灯/窗/食物/雨）
- [ ] 人物有没有生活质感？（不是摆拍）
- [ ] **封面人物是否与正片角色一致？（面部特征、发型、服装是否匹配参考图和正片设定）**
