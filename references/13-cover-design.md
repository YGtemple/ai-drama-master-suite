# 13. 封面设计规范（电影海报风）

> 本文件基于用户指定的标杆账号封面风格拆解。每次出封面前必须读这个文件。

---

## 一、标杆风格核心原则

**封面不是截图加字，是一张电影海报。**

观众刷到封面时，应该像在电影院看到海报一样——被画面氛围吸引，被片名勾起好奇，想点进去看。

## 三、设计规则（从上面总结）

### 1. 构图规则

- **人物在画面中下部或中间，占画面1/2到2/3**，上方或一侧留空给标题
- **中景/全景为主**：拍人的全身或大半身，不要大脸特写怼镜头
- **优先背影、侧脸、低头**：人物不需要看镜头，情绪靠场景传
- **人物穿旧衣服、有生活质感**：不要精致妆造，要真实感
- **画面必须有一个"环境主角"**：路、窗、门、面摊、抽屉、路灯、雪——环境本身就在讲故事

### 2. 标题文字规则

- **标题=片名，4-8字最佳**，像电影名，不写说明文
  - ✅ "望山跑死马""栖野""平安馒头""爱你老妈""女孩"
  - ❌ "她为什么十年不回家""结果全家崩了"
- **字体**：粗体为主，白色（暗底上），可有书法笔触感
- **排版**：
  - **竖排**：在画面左侧或右侧，从上到下，占画面1/3高度
  - **横排**：在画面顶部或中间，居中
- **字要大**：远远就能看见，不要小字
- **副标题（可选）**：极小字，紧贴主标题旁边，补充情绪，可有可无
- **不挡人物脸和关键道具**

### 3. 色调规则

- **电影感冷暖对比**：暗部冷蓝/深蓝，亮部暖黄/橙
- **常见配色方案**：
  - 深夜+路灯黄（雨夜、门口、街道）
  - 黄昏夕阳+远山（归途、离别）
  - 煤油灯+暗褐（怀旧、秘密）
  - 雪+暖黄蒸汽（冬日、食物）
- **整体偏暗**：不要亮堂堂的，暗调才有电影感

### 4. 场景符号库（什么情绪配什么场景）

| 情绪/主题 | 推荐场景元素 |
|---|---|
| 等待/回家 | 雨夜门口、路灯下、村口、车站 |
| 思念/回忆 | 旧抽屉、煤油灯、老照片、旧物、窗 |
| 孤独/归途 | 山间土路、远山、一个人走路、黄昏 |
| 温暖/善意 | 面摊、馒头店、热汤、蒸笼冒气 |
| 错过/遗憾 | 背对背、两个人剪影、黄昏湖面 |
| 亲情/母爱 | 母亲站门口、递碗、牵手、老屋 |
| 成长/兄弟 | 一群孩子、旧楼、学校 |

### 5. 禁止事项

- ❌ 大脸特写怼镜头（我们之前做的那版是错的）
- ❌ 标题写成公众号说明文（"她竟然……""结果……"）
- ❌ 亮堂堂的、平光、没有光影
- ❌ 人物看镜头摆拍感
- ❌ 花哨字体、花字、贴纸

## 四、封面提示词模板

生成封面图时用这个结构：

```
竖屏9:16，电影海报质感。[时间/天气]，[场景描述]，[人物动作和位置]。[关键道具/环境符号]。[光源和色调描述]。画面[左/右/顶]侧竖排[白/其他色]粗体大字"[片名]"，字体有力量感，不遮挡人物。整体电影色调，[冷暖对比描述]，氛围感强。
```

### 模板示例

```
竖屏9:16，电影海报质感。黄昏乡村土路，一位头发花白的老人背着布包站在路口，望向远方。路边一盏老旧路灯刚亮起，发出暖黄光晕。土路边是金黄的稻田。画面右侧竖排白色粗体大字"村口的灯"，字体有力量感，不遮挡老人。整体低饱和度电影色调，暗部深蓝，亮部暖黄，空气透视层次（近实远虚、远景带雾），氛围感强。
```

## 五、高级感视觉关键词（提示词必带）

以下两个词是"显高级"的关键，**每次生成封面/视频提示词都要带上**：

### 1. 低饱和度（Desaturated / Muted）
- 画面颜色不鲜艳、偏灰、克制
- 去掉数码味/综艺感，显电影感
- **提示词写法**："低饱和度色调""色彩克制""去饱和电影调色""muted colors"
- **不要写**："鲜艳""色彩丰富""高饱和"

### 2. 空气介质透视 / 大气透视（Atmospheric Perspective）
- 前景清晰深暗，中景过渡，远景被雾/水汽笼罩变浅变蓝变模糊
- 让二维画面有三层空间深度，不扁平
- **提示词写法**："空气透视层次""近实远虚""远景带薄雾""前景深远景浅""atmospheric haze"
- **实现方式**：场景里加雾、烟、雨、灰尘、水汽；用逆光/侧逆光让空气可见

### 其他加分词
- **浅景深**（shallow depth of field）：人物清晰，背景虚化
- **电影级光影**（cinematic lighting）
- **胶片质感**（film grain / analog look）
- **暗调**（dark moody tone）

## 六、自检清单

出完封面逐条过：

- [ ] 像不像一张电影海报？（不是截图加字）
- [ ] 标题像不像电影名？（4-8字，不是说明文）
- [ ] 人物是中景/全景，在环境中？（不是大脸特写）
- [ ] 标题在画面一侧，不挡主体？
- [ ] 色调有没有冷暖对比？暗调电影感？
- [ ] **是否低饱和度？（不鲜艳、不数码味）**
- [ ] **是否有空气透视层次？（近实远虚、远景带雾、有空间深度）**
- [ ] 环境场景有没有在讲故事？（路/灯/窗/食物/雨）
- [ ] 人物有没有生活质感？（不是摆拍）
- [ ] 远看标题能不能看清？
