# 踩坑经验：《留不住的人》（有参考项目案例）

> 2026-09 项目：基于一个 221 秒河南题材广告片（有参考原片），删掉植入广告后重新制作。本文件记录从 v1 到 v7 踩过的坑。其中「逐镜对齐参考、美术资产全部重做不搬运原片、硬拼不动音频、删广告段补铺垫」等做法，是统一流程里**有参考（原片 / 参考图）分支**的标准动作；无参考的原创项目跳过「拆解对齐参考」那一步即可，其余流程一致。

## 一、拼接铁律：原始片段直接硬拼，不动音频

### 踩了什么坑
v1-v5反复出现"嘴型不对、人物嘴没动就开始说话"的问题。一开始以为是AI生成时嘴型没对上，反复重生成镜头、压缩台词到4-5字一句，越改越乱。

**真相**：原始生成片段本身嘴型和音频是同步的。嘴型错位是因为：
1. 后期拼接时裁剪了片段开头/结尾（掐头去尾），导致音频和视频帧错位
2. 重生成片段时改了提示词，新片段节奏和原来对不上
3. 用-c copy直接拼接导致时间戳错乱（474秒异常）

### 正确做法
- **所有镜头生成完后，直接按顺序硬拼，不裁剪、不调速、不抽帧、不动音频**
- > ⚠️ **本条已更新**：硬拼接优先 concat demuxer＋`-c copy` 流拷贝、零重编码；仅当源规格确实无法统一时才按 06 号 fallback。重编码会引入音画偏移，不再作为默认。以下"重新编码"命令仅作 fallback 参考。
- 拼接用重新编码（libx264 + aac），不要用-c copy（会时间戳错乱）
- 硬拼接 = 片段A结束的瞬间直接接片段B开始的瞬间，一刀不剪一帧不裁
- 嘴型有问题的镜头单独标出来重生成，不要动其他镜头的拼接

### ffmpeg拼接命令（已验证可用）

> ⚠️ **本条已更新**：以下命令为重编码 fallback，仅当 `-c copy` 流拷贝因源规格不统一失败时才使用。默认优先 concat demuxer＋`-c copy` 零重编码拼接。

```bash
ffmpeg -y -f concat -safe 0 -i filelist.txt -c:v libx264 -preset fast -crf 18 -c:a aac -b:a 128k -r 24 output.mp4
```
- 所有片段必须同分辨率同帧率同音频参数（1280x720, 24fps, aac 44100Hz）
- 先ffprobe检查每个片段参数一致再拼
- > ⚠️ **本条已更新**：`-c copy` 直接拼会时间戳错乱（Non-monotonous DTS）是旧经验；当前规则是优先 `-c copy` 流拷贝，仅当源规格确实无法统一时才按 06 号 fallback 重编码。

## 二、删掉植入广告段后，必须补剧情铺垫

### 踩了什么坑
原片221秒里有一段30秒的转转APP植入广告，里面男主说了一句"下周一去杭州"。用户要求删掉广告段。

删掉后出现剧情断层：
- 少年段母亲说"报那么远干嘛？"——但没说报哪里
- 饭馆段女朋友问"真去杭州？"——前面从没提过杭州

观众看到这里会懵：杭州是哪冒出来的？

### 正确做法
删植入广告前，先把广告段里承载的**剧情关键信息**列出来：
- 提到的地名（杭州、深圳、东莞...）
- 人物关系揭示
- 关键决定（下周一走、辞职、分手...）

然后把这些信息**前移到前面对应的剧情段里**，让前后逻辑接上。

本项目修复：在少年段A2-02里，母亲台词从"报那么远干嘛？"改成"报杭州那么远干嘛？咱郑州大学不好吗？"——一句话就把杭州这个地名铺垫了，后面饭馆段"真去杭州"就有根了。

## 三、同一角色不同年龄段，必须用同一张脸

### 踩了什么坑
本剧有少年男主（16岁，高考报志愿）和青年男主（26岁，离婚/工作）两个时期。第一次做的时候，少年男主用了一张圆脸大眼睛的参考图，青年男主用了一张瘦长脸单眼皮的参考图——两个人长得完全不像，观众认不出是同一个人长大。

### 正确做法
- **同一角色的不同年龄时期，面部骨相必须一致**：脸型、眼型、鼻型、眉形要相同，只是年龄感不同（少年更饱满、青年更棱角分明）
- 做法：先生成成年版定妆照，再以它为参考生成少年版（提示词写"同一个人，16岁版本，脸更稚嫩，但五官骨相完全一致"）
- 不要分别独立生成两个时期的脸，那样必然不像
- 生成后抽帧对比：把少年帧和青年帧并排放，看脸型骨相是否一脉相承

## 四、标准制作流程（统一流程，仅「有无参考」之别）

所有项目（原创 / 改编 / 有参考）走同一条流程；区别只在开头要不要多做一步「对齐参考」。

- **无参考（原创）分支**：直接从剧本出发 → 美术资产 → 分镜 → 提示词 → 逐镜生成 → 审核 → 硬拼。
- **有参考（原片 / 参考图）分支**（本项目即此分支）：在统一流程前多做「拆解参考 + 逐镜对齐」，但**美术资产全部重做、不搬运原片素材**。

有参考分支的验证顺序：
1. **先拆解参考素材**：下载原片→转写逐字稿→抽帧→识别幕结构 / 角色 / 场景 / 道具 / 剧情顺序 / 站位 / 机位
2. **逐镜对齐参考**：场景、剧情顺序、台词、站位、机位逐镜与参考对齐（对齐的是叙事与调度，不是搬运画面）
3. **美术资产全部重做**：启动 script-asset-master 重做场景空镜图＋角色定妆照（四宫格）＋道具图三资产，一人一图不重复，**不得沿用或搬运原片素材**
4. **再写分镜和提示词**：每个镜头@对应参考图
5. **逐镜生成视频**：Seedance 2.5，图生视频，台词写进提示词
6. **逐镜检查**：脸崩/站位/肢体/人数，有问题的单独重生成
7. **直接硬拼**：不裁剪不调速不动音频，优先 `-c copy` 流拷贝拼接，仅源规格不统一时 fallback 重编码
8. **有植入广告段时**：删完检查剧情断层，把广告段承载的关键信息前移到前文补铺垫
9. **抽帧检验人物一致性**：跨镜对比同一角色是否长得一致

### 不要做的事
- ❌ 不要为了嘴型压缩台词成4-5字短句（剧情不完整）
- ❌ 不要全片重生成（越改越乱，只改问题镜头）
- ❌ 不要裁剪片段开头结尾（嘴型会错位）
- ❌ ~~不要用-c copy直接拼接（时间戳错乱）~~ ⚠️ **已更新**：当前规则相反——优先 `-c copy` 流拷贝，零重编码；仅源规格不统一时才 fallback 重编码（见上方更正横幅）
- ❌ 不要后期动音频（原始片段自带的语音是同步的）
