# 分镜组标准输出模板（时长 5–30 秒灵活）（图片 Prompt ＋ 视频 Prompt）· 优化版

> 定位：**模块2 分镜设计 → 模块3 提示词生成的标准输出格式**。一个分镜组＝一次 Seedance 2.5 生成片段，时长在 **5–30 秒内按内容灵活设定、不锁定**（15 秒为常用值；对话密集/长镜头合理时可到 20–30 秒，短平快也可 5–10 秒），通常含 3–6 个镜头。组内同时给出"图片提示词 prompt（场景/角色/物品映射）"与"视频提示词 video_prompt（镜头序列）"。
> 层级：本文件是 [02-storyboard-design.md](02-storyboard-design.md) 分镜规则与 [03-prompt-generation.md](03-prompt-generation.md) 提示词规则**之上的标准输出层**——02 管"怎么设计镜头"，03 管"怎么写提示词"，本文件管"分镜组最终交付成什么机器可读格式"。
> 对接：场景/角色/物品三行映射，直接引用资产大师（script-asset-master）产出的场景空镜、角色图、道具图信息库（复刻时全部资产重做后再 @图片 引用）。
> 标签 `（no srt，no music）` 中 `no music`＝无配乐/无 BGM（不混入任何歌曲/旋律 score）；真实环境音（脚步/雨/风/水流/虫鸣鸟鸣/火焰/衣物摩擦/门轴/马蹄/人群/远处犬吠）不受限、照常保留，并可在镜头/配音指令里写明。

---

## 一、输出要求

请严格按照以下自定义格式输出所有分镜。使用 `_::~FIELD::~_` 作为字段分隔符。

- 输出头部固定为：`_::~OUTPUT_START::~_`
- 输出尾部固定为：`_::~OUTPUT_END::~_`
- 第一部分为图片提示词 prompt，第二部分为视频提示词 video_prompt。

### 固定输出格式

```
_::~OUTPUT_START::~_

场景：场景信息库的名称【@图片+对应数字】（如果没有场景信息库映射，则填写自行分析的场景名称）

角色：角色信息库的名称【@图片+对应数字】（如果没有角色信息库映射，则填写自行分析的人物名称）

物品：物品信息库的名称【@图片+对应数字】，物品在画面中的信息（如果没有物品信息库映射，则填写自行分析的物品名称）

_::~FIELD::~_

镜头1：第1个镜头内容

镜头2：第2个镜头内容

镜头5：第5个镜头内容

镜头6：第6个镜头内容

（no srt，no music）

_::~OUTPUT_END::~_
```

## 二、分镜组结构规则（时长灵活，不锁定）

【结构规则】

- **分镜组时长不固定**：在 Seedance 2.5 支持的 **5–30 秒**内，按内容、对白量与节奏合理设定；shot 按参考内容依次顺序排序和设定时长，所有 shot 时长合计＝该组设定时长。**15 秒只是常用默认、不是硬上限**——对话密集或长镜头合理时可做到 20–30 秒，短平快也可 5–10 秒。长运镜可以存在，但必须合理、不拖沓。
- 每个分镜组一般由 **3 到 6 个镜头**组成（组时长更长、信息更多时可适当增加镜头，但仍须保证每镜信息密度）。节奏较慢时用 3 个镜头，节奏较快时用 5 到 6 个镜头。
- 如果该 shot 中有台词，台词数要与时长匹配：普通语速按 **1 秒 ≤ 5 个字**，慢语速角色按 **1 秒 ≤ 3 个字**处理。单个 shot 无法完整承载一句台词时，可拆分到前后镜头，但不能改变原台词。
- 对白密度按组时长控制：**15 秒左右对白不超过 5 句**，更长的组可按比例增加但不堆砌；单句尽量不超过 10 个字。对白过长时必须拆分到连续镜头，保证口型、动作和画面节奏匹配。
- 所有镜头描述字数总和建议**少于 1500 字**（组时长接近 30 秒时可适当放宽，但不写废话）。
- 每个镜头必须写清楚：对准谁、对准哪里、表情是什么、主体动作、跟随动作、画面信息点、镜头位置与运动。

---

## 三、镜头写法强制规则

每个镜头必须包含以下信息：

- **景别**：中景 / 近景 / 特写 / 大特写
- **机位**：平视 / 俯拍 / 仰拍 / 过肩 / 侧逆光 / 门缝窥视
- **运动**：固定 / 轻推 / 拉近 / 甩镜 / 手持微抖 / 跟拍 / 快速拉焦 / 急停
- **主体**：角色 / 道具 / 环境
- **动作**：主体正在做什么
- **跟随动作**：手指、眼神、呼吸、衣角、脚步等微动作
- **信息点**：画面必须让观众看到什么

推荐写法：

> 镜头1：3s 中景，平视，35mm，轻推。镜头对准角色上半身和手部，角色皱眉，手指扣紧桌边，指节发白，肩膀轻微前倾。画面中能看到桌面上的关键物品，镜头从三分构图慢慢推到居中，情绪值 40%。

## 四、台词与配音指令规则

如果镜头中有对白，必须加入配音指令。格式：

```
【配音指令：角色名｜VoiceID｜状态（身体/情绪/目标）｜语气特点（音量/语速/气息/尾音/情绪色彩）：对白原文】
```

示例：

```
【配音指令：谢怜｜青年公子音｜状态（紧绷/警惕/试探）｜语气特点（低音量/语速快/气息紧/尾音收住）：来了。若邪，去！】
```

注意：

- 对白必须严格使用输入文案原词，不允许改写；旁白、内心 OS 也不能改词。
- 同一角色只能使用固定 VoiceID；可以改变状态和语气，但不能改变声线设定。

> ⚠️ 边界见本文第七节：**配音指令是写进视频 prompt、指导视频模型"直接生成"语音的语气/声线设定，不调用 TTS。**

## 五、示例 1（约15秒）（优化版）

**输入内容**

> 黑暗的树林，阴风怒号。轿子周围倒伏着数十只瑟瑟发抖的恶奴。
> 突然，所有的嘈杂声瞬间消失，死一般的寂静。
> 清脆、缓慢的铃铛声：叮铃……叮铃……
> 镜头聚焦在破旧的喜轿帘子上，帘子微微颤动。
> 谢怜（OS）："来了。若邪，去！"
> 谢怜袖中的白绫死寂不动。
> 谢怜眼神一凛，指尖微颤。
> 谢怜（OS）："不动？若邪对邪气最敏感，它没反应，难道来者……没有杀气？"

**输出示例**

```
_::~OUTPUT_START::~_

场景：在与君山深处·迷阵中

角色：新娘服装谢怜

物品：喜轿，谢怜坐在喜轿中

_::~FIELD::~_

场景：在与君山深处·迷阵中

角色：新娘服装谢怜

物品：喜轿，谢怜坐在喜轿中

镜头1：3s远景，俯拍，24mm，手持轻微下压。镜头对准黑暗树林和停在小路中央的红色喜轿，轿子周围倒伏着数十只瑟瑟发抖的恶奴，破碎衣角贴着地面抖动。阴风卷起枯叶，画面边缘轻微晃动，声音从嘈杂迅速抽空，情绪值35%。

镜头2：2s中景，平视，50mm，固定后快速拉焦。镜头对准破旧喜轿的帘子，帘角轻轻颤动，红布边缘磨损，轿门缝里只有暗色。清脆铃铛声响起：叮铃……叮铃……镜头焦点从轿帘转到轿内阴影，情绪值50%。

镜头3：3s近景，轿内平视，85mm，慢推。镜头对准新娘服装谢怜的下半张脸和盖头边缘，谢怜下巴绷紧，手藏在红袖下微微抬起。红盖头挡住大半张脸，只露出紧抿的嘴角。【配音指令：谢怜｜青年公子音｜状态（紧绷/警惕/试探）｜语气特点（低音量/语速快/气息紧/尾音收住）：来了。若邪，去！】

镜头4：2s特写，俯拍，85mm，轻推急停。镜头对准谢怜红袖里的白绫，白绫垂在袖口内侧，死寂不动。谢怜手指向前轻推，指尖停在半空，白绫没有任何反应，画面落在静止的白绫上，情绪值60%。【配音指令：谢怜｜青年公子音｜状态（疑惑/冷静分析/确认异常）｜语气特点（低音量/语速中/气息压住/尾音短）：不动？】

镜头5：2s大特写，平视，85mm，快速推近。镜头对准红盖头阴影下谢怜的双眼，谢怜眼神一凛，瞳孔轻微收缩，睫毛下压，指尖在画面下方微微一颤。【配音指令：谢怜｜青年公子音｜状态（疑惑/冷静分析/警觉升高）｜语气特点（低音量/语速中/气息稳/尾音收干净）：若邪对邪气最敏感。】

镜头6：3s近景，轿内侧逆光，50mm，慢拉到固定。镜头对准谢怜坐在喜轿中的身影，红盖头微微晃动，手指慢慢收回膝上，袖口里的白绫仍然不动。画面最后停在他压低的脸和静止的袖口之间，为下一镜外来者靠近做承接，情绪值75%。【配音指令：谢怜｜青年公子音｜状态（警觉/疑惑/压住呼吸）｜语气特点（低音量/语速慢/气息紧/尾音压低）：它没反应，难道来者……没有杀气？】

（no srt，no music）

_::~OUTPUT_END::~_
```

## 七、使用边界澄清（与全局铁律对齐，避免误读）

1. **配音指令 ≠ TTS**：`【配音指令…】`是**视频 prompt 的一部分**，用于描述角色声线（VoiceID 锚定）、情绪状态与语气，指导 **Seedance 视频模型直接生成**带该语音的片段；**不调用任何 TTS / 语音合成工具**（符合铁律 7 与用户偏好）。VoiceID 仅作"同一角色全片固定声线"的一致性锚点。
2. **"甩镜"是镜内运镜，不是后期转场**：示例中的甩镜（whip pan）发生在同一个 15 秒生成片段内部，属于镜头运动，可保留；**片段之间的后期衔接仍只允许硬切/硬拼接**，不使用任何转场特效。
3. **三行映射对接资产大师**：场景/角色/物品名称优先取资产信息库并 `@图片N` 引用；仿照复刻时，所有场景、角色、道具资产必须先由资产大师重做，再映射引用，不搬运原片。
4. **零字幕 / 无配乐 / 原画质 / 硬拼接**：`（no srt，no music）`必须保留（`no music`＝无配乐/无 BGM，真实环境音照常保留）；最终交付为原画质、零压缩、流拷贝硬拼接的粗成片，镜头时长合计＝该组分镜设定时长（5–30 秒内灵活），与 Seedance 2.5 单次生成对齐。
