# 声音/配乐参考（仅用户后期自理）

> ## ⚠️ 性质声明（先读，防止误用）
> 本文件全部内容**仅为用户在自己的后期软件（剪辑/混音）里配乐时的参考建议**。技能产出的单镜视频与硬拼接成片**默认不含任何人为配乐 BGM**（全局铁律26）：视频提示词保留 `（no srt，no music）` 标签，AI **不得**依据本文件在生成的视频里添加 BGM。画面里由模型直接生成的台词、真实环境音（脚步/雨声/风声等）照常保留，不受本文件影响。
> 一句话：**这里教的是「你（用户）后期自己怎么配乐」，不是让 AI 在视频里配乐。**

---

## 定位与边界

- **本文件管什么**：用户拿到技能交付的「零配乐 BGM 粗成片」后，在自己的剪映 / Pr / DaVinci 里**自己铺配乐、做声音设计**时怎么判断对错。
- **本文件不管什么**：技能在任何环节（剧本/分镜/提示词/生成/硬拼接）都**不生成、不添加、不混入 BGM**；提示词里的 `（no srt，no music）` 照留，真实环境音（脚步/雨/风/水流/虫鸣鸟鸣/火焰/衣物摩擦/门轴/马蹄/人群嘈杂/远处犬吠）照留。
- **素材来源**：本清单脱胎于成片反馈中 A 组「配乐/声音设计」的五条高频翻车点 + 一条总审美习惯，按「问题 → 为什么 → 怎么做」逐条给出。

## 一、配乐情绪要贴题材（别套错情绪）

- **问题**：题材是压迫、悲壮、解放、强冲突，却铺了「治愈系 / 平淡叙事」的轻柔音乐，情绪完全错位。
- **为什么**：配乐是情绪的第二台词。题材沉、音乐飘，观众会觉得「假」「违和」，悲壮出不来、压迫压不住。
- **怎么做**：

| 题材段落 | 该用的配乐气质 | 别用 |
|---|---|---|
| 压迫 / 被审 / 绝境 / 旧社会 | 沉郁、厚重、紧张、低频持续音、稀疏不和谐音 | 治愈钢琴、明亮弦乐全奏 |
| 悲壮 / 牺牲 / 生离死别 | 厚重、克制、带呼吸感的长线条 | 甜腻治愈、流行抒情 |
| 强冲突 / 对峙 / 爆发 | 紧张、推进、渐强、鼓点/脉冲 | 舒缓氛围垫乐 |
| 真正的温暖 / 和解 / 重逢 | 钢琴单音 / 温暖弦乐渐强，只用在这一处 | 把治愈乐铺满全片 |

> 治愈系、平淡叙事的音乐**只能用在真正温暖的那一小段**，不能当成万能背景乐从头铺到尾。

---

## 二、乐器要符合剧情时代与地域（别穿越）

- **问题**：年代剧 / 历史剧 / 旧社会题材里，出现现代乐器、现代治愈钢琴、合成器 pad，一听就是当代配乐，瞬间出戏。
- **为什么**：观众对「什么时代、什么地方有什么声音」有直觉。乐器穿越 = 服化道穿越，年代质感全毁。
- **怎么做**：
  1. **配乐前先回答两个问题**：这是什么时代？这是什么地方？（年代/民国/旧社会/民族地区/战争年代）
  2. **按时代与地域选配器**：年代/旧社会/民族题材，优先用**年代配器与民族乐器**（如板胡、二胡、笛箫、琵琶、筝、马头琴、大提琴低音区等贴合语境的组合），而不是现代治愈钢琴 / 现代管弦全奏 / 电子音色。
  3. **现代都市/当代题材**才用现代钢琴、现代弦乐、电子音色；不要把当代配器套进年代戏。
  4. 拿不准时，先找两部同年代、同地域的电影听它们用什么乐器，照着那个时代感选，而不是照着热门歌单选。

## 三、音乐只在情绪点进，叙事/对话段别铺满

- **问题**：没判断音乐该在哪进，结果从头到尾铺满 BGM，对话、叙事也压在音乐底下，又吵又累。
- **为什么**：音乐是「调味料」不是「白米饭」。铺满=没有重点，该炸的地方反而炸不出来；对话段有音乐挡着，台词也听不清。
- **怎么做**：
  - **音乐只在情绪点进入**：转折、爆发、留白后的升华、关键道具出现、翻盘台词前后——这些点才让音乐进来。
  - **叙事段 / 对话段 / 日常交代段**：不铺音乐，或只留极薄的一层垫底、甚至直接用真实环境音顶着。
  - 进点示例（配合 11/12 号年代剧结构）：温暖高潮后留 5–8 秒**真实环境音 + 留白**，音乐别盖上去；翻盘台词前 0.5 秒所有声音骤停，台词爆完再让音乐进。
  - 原则：**让观众在「没音乐」的地方也能听懂、能代入，音乐一出来就是在推情绪。**

## 四、音量要克制、铺垫渐入；有人声自动压低（Ducking）

- **问题**：音乐一上来就很大，压过人声和画面，很突兀；对话还在说，配乐突然冒出来抢戏。
- **为什么**：观众首先要听清台词。配乐一旦比人声还响，叙事就崩了；硬切式大音量进出，听感非常跳。
- **怎么做**：
  - **铺垫渐入**：音乐淡入进来，不要「啪」一下满音量开始；情绪落了再淡出收住。
  - **音量克制、留动态**：整体配乐压在人声之下，不要顶到最大；保留音乐自己的强弱起伏，别一铺到底一个响度。
  - **有人声自动压低（Ducking）**：台词/对白出现时，配乐自动 ducking 降下来让台词干净；人声一停，音乐再托上去。
  - **音量层级（用户后期混音参考）**：台词 > 动效音 > 配乐 BGM ≈ 环境音；配乐永远不是第一听觉。

---

## 五、不重复、不循环；结尾别硬加一段

- **问题**：到结尾了又把开头那段音乐重复放一遍，循环感很重；或者结尾硬塞一段升华音乐。
- **为什么**：同一段配乐反复用，观众一听就出戏、觉得偷懒；结尾硬加音乐是「生怕观众没感受到情绪」，反而显得没底、拖泥带水。
- **怎么做**：
  - **不重复 / 不循环同一段配乐**：全片尽量用不同的乐段，别让一段旋律来回播。
  - **结尾宁可干净**：情绪收在台词、收在真实环境音、收在黑场留白上都可以；**不要为了「升华」在结尾硬贴一段配乐**。
  - **「结尾又重复一段」是明确忌讳**——结尾应该是干净收束或干净留白，而不是把主题歌再唱一遍。
  - 需要余韵时，用一个单音、一记环境音、一段静默收尾，比硬加配乐高级。

## 六、审美总纲：多看电影，少看抖音

- **问题**：配乐的听觉习惯是被短视频/抖音神曲养出来的——满、响、高频、强律动、情绪直给，套到短剧上就显廉价。
- **为什么**：电影的声音是低频、克制、有质感的；它靠留白、靠动态、靠配器细节说话，而不是靠「铺满」和「炸响」。
- **怎么做（一条总习惯）**：
  - **每做完一段 / 一整集，自己先从头到尾完整看一遍、听一遍**：配乐进点对不对、音量突不突兀、有没有重复、台词干不干净。
  - **养耳朵：多看电影、少看抖音**——去听电影里的配乐怎么进、怎么让、怎么收。
  - 记住电影声音的三个关键词：**低频（沉得下去）、克制（不铺满）、有质感（配器干净、有动态）**。拿不准配乐好不好时，拿这段和电影比，别和热门短视频比。

## 七、后期配乐自检清单（用户自己过一遍）

- [ ] 配乐情绪贴题材了吗？压迫/悲壮段有没有误用治愈系？
- [ ] 乐器符合这个时代、这个地方了吗？年代戏里有没有冒出现代钢琴/电子音色？
- [ ] 音乐是不是只在情绪点进？叙事/对话段有没有铺满？
- [ ] 音乐是渐入的吗？有人声时有没有自动压低（Ducking）？整体音量克制吗？
- [ ] 有没有重复/循环同一段？结尾有没有硬加一段、宁可留白收束？
- [ ] 拿这段的听感和电影比——低频、克制、有质感做到了吗？
